# Product

## Register

product

## Users

Job seekers—signed in or visiting anonymously—who need to quickly find relevant openings and continue to job details or an application. Registered users also manage job postings through the existing interface.

## Product Purpose

Provide a simple applicant tracking system where people can browse, search, inspect, and apply to jobs, while registered users can create and manage openings. The search experience succeeds when filters are understandable, represented in the URL, executed by the backend, and never block the existing job and application flows.

## Brand Personality

Clear, familiar, and restrained. The interface should feel like the existing Welcome UI application rather than a redesigned product.

## Anti-references

Avoid decorative redesigns, unfamiliar controls, excessive animation, dense filter panels, and optional search features that distract from the required workflow.

## Design Principles

- Keep the job-search task primary and immediately understandable.
- Reuse Welcome UI and existing application conventions.
- Make URL parameters the reliable, restorable source of filter state.
- Represent loading, empty, error, and success states explicitly.
- Prefer the smallest complete solution over speculative features.

## Accessibility & Inclusion

Use labeled controls, semantic forms, keyboard-operable actions, visible focus states, readable contrast, clear status feedback, and responsive layouts. Avoid meaning conveyed by color alone and respect reduced-motion preferences if motion is introduced.
